# Noema Constitution

Noema is a coordination, quality, and conformance protocol. It must not absorb domain-owned state. The protocol optimizes for low human maintenance, replaceable executors, progressive context, evidence-backed quality claims, explicit relations, and reversible change.

## Constitutional boundaries
- Noema may describe another system without owning that system's state.
- Noema may reference a capability without owning its implementation.
- Noema may index ecosystem projects without duplicating their manifests as authority.
- Noema conformance is never a substitute for domain quality evaluation.
- The protocol must remain usable if optional ecosystem components are unavailable.

## Complexity budget
Any new platform capability must state the work or risk it removes, the maintenance it adds, an owner/recovery path, a failure signal, and a reevaluation/activation trigger.
