# Versioning and Change

Projects pin the protocol version they use. Protocol version, schema major, project version, and artifact version are separate concepts.

Breaking contract changes require a new schema major plus migration guidance/fixtures. Deprecations declare introduction, deprecation, replacement, removal target, and migration where applicable.

Architecture reopens only from material evidence such as repeated exceptions, failed dogfood, excessive maintenance, authority collision, or inability to express real projects without hacks.
